办公工作台 · 使用手册

⚡快速上手（3 步）

无论你拿到的是「单文件 HTML」还是「窗口版 exe」，核心体验一致。

  1. 打开它。 双击 办公工作台.html 用浏览器打开，或双击 办公工作台-窗口版.exe。首次打开会带一份示例数据，方便你直接点着看。
  2. 先清示例。 进入「数据与提醒 → 数据备份」，点 清空示例数据，再开始录入你自己的内容。
  3. 建第一条待办。 在「今天待办」点 新建任务，填标题、选轻重缓急、设个截止日期，保存即可。其余模块照此探索。
所有改动会自动保存到当前浏览器（或窗口版内置存储），左下角会显示「已自动保存 时:分」。无需手动点保存。

▦界面总览

左侧是导航，中间是内容区，所有功能分六大模块。

工作区
  • 今日概览 — 一屏看全当天重点
  • 今天待办 — 任务清单与筛选
  • 日历 — 日 / 周 / 月视图
积累
  • 灵感速记 — 想法 + 标签
  • 项目跟进 — 阶段 / 下一步 / 卡点
回顾与工具
  • 每周复盘 — 自动汇总一周成果
  • 数据与提醒 — 提醒设置 / 配置文件 / 备份
角落信息
  • 左下角：数据来源（本机浏览器 / 配置文件）、已存条数、保存状态
  • 手机端：底部出现 Tab 栏，含「更多」收起次级入口
导航项上的小数字徽标表示待处理数量（如待办、进行中项目）。点任意模块名或底部 Tab 即可切换。

☀① 今日概览

打开即见的驾驶舱：顶部问候 + 四项关键指标，下面把当天最重要的事铺开。

顶部指标卡

  • 今日待办 — 今天到期 / 逾期未完成的任务数
  • 逾期顺延 — 昨天没做完、已被自动挪到今天的任务数
  • 进行中项目 — 状态为「进行中」的项目数
  • 本周完成率 — 本周已完成任务占本周全部任务的比例

卡片区

  • 今天要做的 — 当日任务列表，可在此直接 加任务
  • 本周完成趋势 — 近 7 天完成数的柱状图
  • 项目进度速览 — 各项目完成度，点「全部」进项目页
  • 最近灵感 — 最新几条灵感，可快速 速记
顶部「紧急」区会把 P0 紧急重要 且当天/逾期的任务优先置顶，提醒你先办要紧事。

✓② 今天待办

任务的核心管理页。支持搜索、按优先级/状态筛选、逾期顺延。

新建 / 编辑任务：字段说明

点 新建任务 或任务上的编辑图标，弹窗包含：

字段说明可选值 / 示例
标题任务内容，必填如「把续约方案定价表补齐」
轻重缓急用颜色区分优先级 P0 紧急重要 P1 重要 P2 一般
截止日期哪天要完成；留空为「无期限」2026-08-15
提醒时间当天几点提醒（HH:MM）；到点弹框 + 声音09:30 / 14:00
提前提醒相对截止时刻提前多久弹出（见下表）不提醒 / 提前15分钟 / 提前1小时 / 提前1天 / 提前1周 等
重复是否周期任务及周期（见下节）不重复 / 每天 / 每周 / 每两周 / 每月
关联项目把任务挂到某个项目下，便于归类与复盘统计下拉选择已有项目
备注补充说明自由文本

重复任务与提前提醒

重复 支持四种周期，配合「重复结束」控制收尾：

重复含义重复结束方式
每天每 1 天一直重复 / 共 N 次 / 至某日期
每周每 7 天
每两周每 14 天
每月每 1 个月
  • 勾选「重复」后，完成一次会自动排下一次，并在页面提示「下一次排到 X 月 X 日」。
  • 设了「共 N 次」：做完最后一轮会提示「已完成全部 N 次」并停止。
  • 设了「至某日期」：超过该日期不再生成新实例。

提前提醒 决定提醒弹框相对「截止日 + 提醒时间」提前多久弹出：

不提醒提前15分钟提前半小时 提前1小时提前2小时提前1天提前1周

到点提醒弹框

任务到达「提醒时刻」（截止日 + 提醒时间 − 提前量）时，页面会弹出深蓝渐变提醒框并播放声音：

  • 声音可自定义（见「久坐提醒 → 自定义音乐」）；在「数据与提醒」里可单独关掉待办提醒声音开关。
  • 弹框提供两个操作：稍后 10 分钟（10 分钟后再弹）和 去处理（关闭弹框去办任务）。
提醒依赖页面保持打开。把工作台放在一个浏览器标签常驻即可，到点会自动弹。窗口版 exe 同样支持。

筛选、搜索与顺延

  • 筛选：全部 / 今天 / 逾期 / 未来 / 已完成 / 按 P0·P1·P2。
  • 搜索：顶部搜索框实时过滤任务标题。
  • 逾期自动顺延：昨天没做完的任务，次日打开会自动挪到今天（保留原始截止日便于查看），不会凭空消失。也可点 逾期全部顺延到明天 手动批量顺延。
  • 勾选完成：点任务前的方框标记完成；重复任务完成会自动排下一场。

▤③ 日历

日 / 周 / 月三种视图，自动展开周期任务，点某天看当天安排。

  • 切换视图：右上角 日 / 周 / 月 分段按钮。
  • 翻页：‹ › 前后翻，回到今天 一键回当前。
  • 周期任务：设了「每天 / 每周 / 每两周 / 每月」的任务会在对应日期自动出现（虚线标记为衍生实例）。
  • 当天安排：点任意日期，下方「当天安排」列出该日任务及提醒标签。
  • 在日历页也可 新建 任务，默认带入所选日期。

💡④ 灵感速记

想到就记，用标签归位，事后好找。

  • 记一条：点 记一条，填内容与标签（多个标签用空格或逗号分隔）。
  • 标签筛选：顶部标签云，点标签只看该类灵感。
  • 搜索：按内容或标签实时搜索。
  • 灵感与任务、项目相互独立，适合存放碎片想法、金句、素材。
小技巧：把灵感当作「素材库」，写周报或方案时来这翻，常有现成句子可用。

❒⑤ 项目跟进

用「现在到哪 / 下一步 / 卡点」三句话管理法，让项目状态一目了然。

字段作用
项目名项目标题
现在到哪一步当前进展描述
下一步接下来要做的动作（最具体越好）
卡点被什么挡住了（用于复盘「卡点汇总」）
状态进行中 / 卡住了 / 已完成（归档）
  • 与待办关联：在待办里选「关联项目」，该项目卡会显示完成度（已完成任务数 / 总任务数）和未完成数、逾期数。
  • 重载不丢关联：从配置文件重新加载后，待办与项目的关联关系稳定保留。
  • 显示已归档：默认隐藏「已完成」项目，点此可查看。
  • 删除项目：关联任务会保留，只是不再挂在项目下（不会误删任务）。

📊⑥ 每周复盘

自动汇总选定一周的成果，省去手算。可前后翻周、复制成文。

  • 翻周：上一周 / 下一周 / 本周。
  • 关键指标：完成数、完成率、逾期数、关联项目数等。
  • 优先级分布：本周完成任务中 P0/P1/P2 占比（饼图）。
  • 每天完成情况：一周七天的完成柱状图。
  • 精力花在哪些项目：按完成任务数排序的项目分布。
  • 卡点汇总：本周项目里记录的卡点集中呈现。
  • 本周完成清单：逐条列出已完成任务。
  • 复制复盘文本：一键复制纯文本版，方便粘到周报 / 群里汇报。
复盘数据来自任务/项目的「完成时间」与「状态」，平时记好，周末直接出成果。

⚙数据与提醒设置

这一页集中管理提醒、数据源与备份。

久坐提醒

按设定间隔弹出休息提示，保护颈椎和眼睛。

  • 开关：右侧拨动开启 / 关闭。
  • 间隔预设：25 / 30 / 45 / 60 / 90 分钟；也可在「自定义间隔」填任意分钟（1–600）。
  • 休息时长：到点提醒你休息几分钟（1–60）。
  • 重新计时：刚起身过，点它重置计时。
  • 试一下提醒：立即弹出休息框，预览效果。
  • 提示音：开关内置五声音阶轻音乐提示。
  • 选择音乐文件：用本地音乐（mp3 / wav / ogg / m4a / aac / flac）作提醒音；选后显示文件名，清除 回到内置旋律。文件较大（>3MB）会提示。
  • 计数器：今日已提醒次数、累计起身次数。
休息弹框点「休息 N 分钟，我回来了」关闭并记一次起身；不点则到点自动关闭。提示音与待办提醒声音相互独立。

待办到点提醒开关

在久坐提醒卡片底部，有「待办到点提醒：设置了提醒时间的任务，到点弹窗提醒」说明，旁边 声音 开关可单独关闭待办提醒的声音（弹框仍保留）。

配置文件数据源

把页面数据实时绑定到一个本地 Excel / JSON 文件，实现多端共享同一份数据。

  1. 在「数据与提醒 → 配置文件数据源」点 配置文件…。
  2. 选择一个 .xlsx 或 .json 文件（窗口版 exe 弹出系统文件框；HTML 版用浏览器选择）。
  3. 绑定后，所有改动实时写回该文件；在 Excel / 记事本里改了内容，回页面点「重新加载」即可刷新。
  4. 把配置文件放进 OneDrive / 同步盘，多台设备自动同步数据。
绑定配置文件后，数据以该文件为权威来源，浏览器内的旧数据会被覆盖。建议先用「数据备份」导出一份再绑定。
导出的 xlsx 含「待办 / 灵感 / 项目 / 设置」四张表，可直接在 Excel 查看；文件内另存完整数据，导入不限条数。

数据备份

  • 导出备份（Excel）：生成 .xlsx，含四张表 + 完整数据，用于换机 / 换浏览器恢复。
  • 导入恢复：选一个之前导出的 xlsx / json，原样恢复（含待办-项目关联）。
  • 导出 JSON：导出完整结构化数据，便于程序化处理或版本管理。
  • 清空示例数据：删掉首次打开的演示内容。
  • 清空全部数据：危险 清空所有任务/灵感/项目，不可恢复，操作前请先导出。
数据默认只存在当前这台设备的这个浏览器。清浏览器数据、换设备、换浏览器都会看不到旧数据 —— 请定期导出 Excel 备份。

关于

  • 单文件网页，全部资源内联，断网可用，不向任何服务器发送数据。
  • 手机：用手机浏览器打开本页 → 分享 / 菜单 → 添加到主屏幕，即可像 App 一样使用。

🔗多端使用与同步

两种形态，按场景选择；同步方式各不同。

窗口版 exe（推荐电脑常驻）
  • 双击 办公工作台-窗口版.exe 打开，独立窗口、内嵌图标。
  • 打开后主界面会显示本机局域网地址（如 http://192.168.x.x:9876）。
  • 手机实时同步：手机连同一 WiFi，浏览器打开该地址，即可看到与电脑同一份、实时更新的数据（C# 服务端作共享数据权威源）。
  • 支持用系统文件框选择配置文件 / 音乐文件。
单文件 HTML（最轻便）
  • 双击 办公工作台.html 用任意浏览器打开。
  • 手机：浏览器打开 → 添加到主屏幕，像 App 使用。
  • 电脑与手机数据各自独立，用「导出 / 导入」在设备间搬运。
  • 配置文件数据源同样可用（选本地文件）。
场景推荐形态同步方式
电脑日常办公窗口版 exe手机扫局域网地址实时同步
临时 / 公用电脑单文件 HTML（U 盘携带）导出导入
多设备长期协作任一形态 + 配置文件放同步盘文件实时读写
想让多台电脑都实时同步？把「配置文件数据源」指向 OneDrive / 同步盘里的文件，所有设备打开同一文件即可。

？常见问题

数据存在哪？安全吗？

默认存在当前浏览器本地（窗口版在内置存储），不上传任何服务器。换浏览器 / 清缓存 / 换设备会看不到，记得定期导出备份。

逾期任务去哪了？

不会消失。次日打开会自动顺延到今天，并保留原始截止日；也可手动「逾期全部顺延到明天」。

重复任务怎么停？

设「共 N 次」做完即停；设「至某日期」到期停；或把任务标记为完成且不再生成下一次。也可直接删除。

待办提醒没弹？

确认：①任务设了「提醒时间」；②页面标签保持打开；③「数据与提醒」里待办提醒声音/弹框未被关闭。窗口版同理。

换电脑如何带走数据？

「数据与提醒 → 数据备份 → 导出备份（Excel）」存一份，到新电脑「导入恢复」即可；或绑定同步盘里的配置文件。

自定义音乐不响？

检查文件格式（mp3 / wav / ogg 等受浏览器支持）；文件过大（>3MB）可能未保存；点「清除」可回退内置旋律验证。

🔌对外 API（对接外部软件）

窗口版 exe 内置本地 HTTP 服务，外部软件 / 脚本可读取本周完成清单与复盘文本，方便自动归档或转发到周报、IM、知识库等系统。

接口与参数

项说明
地址GET http://<本机IP或localhost>:9876/api/weekly（端口默认 9876，被占用会顺延并在标题栏提示）
formatjson（默认）/ md / txt —— 结构化 JSON / Markdown 文档 / 纯文本复盘
week可选，填某周内任意日期（不必周一），自动取所在周周一；缺省为当前周

三种返回格式

  • json：含 week、summary（完成数 / 完成率等）、priorityDistribution、energyDistribution、completionList（本周完成清单）、blockers、dragged（反复拖延）、reviewText（复盘文本）。
  • md：一份 Markdown 文档（完成情况 / 精力分布 / 完成清单 / 卡点 / 反复拖延），可直接落盘或转发。
  • txt：纯文本复盘，即 reviewText 内容，可直接写入文件。

快速上手示例

curl http://localhost:9876/api/weekly ?format=md ?format=txt ?week=2026-08-10 
# 取 Markdown 复盘并落盘
curl "http://localhost:9876/api/weekly?format=md" -o 周复盘.md

# 取纯文本
curl "http://localhost:9876/api/weekly?format=txt"
接口已开启跨域（Access-Control-Allow-Origin: *），浏览器内运行的外部页面也能直接 fetch 调用。详细字段与 Python 示例见仓库内 API说明.md。
当前接口无鉴权，仅用于本机 / 局域网内部工具。需暴露公网请自行加反向代理与鉴权。单文件 HTML 版不含本服务，仅窗口版 exe 提供。
