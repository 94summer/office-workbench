# 个人办公工作台

## 用哪个文件

| 文件 | 说明 |
|---|---|
| **办公工作台-窗口版.exe** | ⭐ 推荐。双击直接弹出应用窗口，无需浏览器 |
| **办公工作台.html** | 单文件网页，双击用浏览器打开，断网可用 |
| ~~办公工作台.exe~~ | 旧的控制台版，**已废弃，可以删除** |

---

## 窗口版怎么用

双击 `办公工作台-窗口版.exe`：

- 直接弹出一个应用窗口，里面就是工作台界面
- 首次启动约 5～10 秒（要解压运行时 + 初始化内核），之后 1～2 秒
- 窗口底部状态栏显示 **手机访问地址**，旁边有「复制手机地址」「用浏览器打开」两个按钮
- 关掉窗口即完全退出，不留后台进程

### 手机怎么用

1. 电脑上打开窗口版
2. 点底部「复制手机地址」，或直接看状态栏上的 `http://192.168.x.x:9876/`
3. 手机连**同一个 WiFi**，浏览器输入这个地址
4. 手机浏览器 → 分享 → **添加到主屏幕**，就能当 APP 用

> 首次手机访问若打不开：Windows 防火墙弹窗要勾选「专用网络」并允许。

## 数据存在哪

数据保存在**各自设备的浏览器本地存储**里，不上传任何服务器。

| 使用方式 | 数据存放位置 |
|---|---|
| 窗口版 exe | `C:\Users\<你>\AppData\Local\个人办公工作台\WebView2\` |
| 电脑浏览器访问 `127.0.0.1:9876` | 该浏览器的本地存储 |
| 手机访问 | 手机浏览器的本地存储 |

**这三处的数据是相互独立的。** 换设备、跨端同步，请用页面上的「导出备份 / 导入」按钮搬运（Excel 格式）。

⚠️ 清理浏览器数据会导致记录丢失，攒到 20 条时页面会提醒导出一次。

## 常见问题

**双击没反应 / 窗口一闪而过**
先看 exe 同目录有没有 `启动错误日志.txt`。最常见原因是 9876 端口被别的程序占了——程序会自动改用 9877～9896，状态栏会提示。

**提示「已经在运行」**
任务栏里找已打开的窗口。找不到就在任务管理器结束「办公工作台-窗口版.exe」后重试。

**Windows 提示「未知发布者」**
点「更多信息」→「仍要运行」。这是未做数字签名的正常提示。

## 功能清单

- 今天要处理：逾期任务 / 卡住的项目置顶标红，昨日未完成自动顺延并记录顺延次数
- 待办：优先级四档、截止日期 + 提醒时间、按日期分组、一键顺延
- 日历：日 / 周 / 月三视图，支持每日 / 每周 / 每月周期任务
- 灵感速记：打标签、按标签筛选
- 项目跟进：当前阶段 / 下一步 / 卡点，关联待办并显示进度
- 每周复盘：完成数、优先级分布、项目精力占比、卡点汇总（内联 SVG 图表）
- 久坐提醒：间隔自定义，圆环倒计时
- Excel 导出 / 导入备份，20 条时提醒
- PC 双栏 / 手机底部 Tab 单列自适应

## 源码结构

```
src/                拆分的源文件（01_head ~ 06_app）
build.js            拼接成单文件 HTML
app/gui/            WinForms + WebView2 桌面版工程
app/cs/             旧控制台版工程（已弃用）
app/out/            exe 发布输出
```

重新构建：

```bash
node build.js                                    # 生成 办公工作台.html
cp 办公工作台.html app/gui/app.html
cd app/gui && dotnet publish -c Release -r win-x64 -o ../out
```
